# Dibyajyoti Jena - Portfolio

A responsive personal portfolio website for an MCA student and aspiring web developer.

## Files
- `index.html` - Portfolio structure
- `style.css` - Responsive styling
- `script.js` - Navigation and dynamic year

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository named `<your-username>.github.io`.
2. Upload these files to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and open `https://<your-username>.github.io/`.

## Before publishing
- Replace the sample GitHub and LinkedIn links with your actual profiles.
- Replace sample projects with your real projects.
- Add your resume PDF if you want a resume download button.
- Add your actual MCA college/university details.
